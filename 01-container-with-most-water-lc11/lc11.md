# LeetCode 11 — Container With Most Water

## Problem Statement

You are given an integer array `height` of length `n`.  
Each element represents the height of a vertical line drawn on the x-axis at index `i`.

Any two lines at indices `i` and `j` (with `i < j`) form a container that can hold water.

The amount of water the container can store is:

```
area = min(height[i], height[j]) * (j - i)
```

Your task is to find the maximum possible area of water a pair of lines can contain.

**Input:**
- `height` — array of non-negative integers

**Output:**
- The maximum area (integer)

**Constraints:**
- `2 <= height.length <= 10^5`
- `0 <= height[i] <= 10^4`

---

## Explanation (Two-Pointer Technique)

A brute-force solution checks all pairs `(i, j)` which takes `O(n^2)` time.

The optimal solution uses two pointers:

1. Start with:
   - `left = 0`
   - `right = n - 1`
2. Compute the area:
   ```
   min(height[left], height[right]) * (right - left)
   ```
3. Update `maxArea` if needed.
4. Move the pointer pointing to the shorter line.
5. Continue until pointers meet.

**Time Complexity:** `O(n)`  
**Space Complexity:** `O(1)`

---

## Example Input

```
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
```

## Example Output

```
49
```
