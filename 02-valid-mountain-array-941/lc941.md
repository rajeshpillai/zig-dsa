# LeetCode 941 — Valid Mountain Array
URL: https://leetcode.com/problems/valid-mountain-array/description/

## Problem Statement

Given an array of integers `arr`, return `true` if and only if it is a **valid mountain array**, otherwise return `false`.

An array `arr` is a valid mountain array if:

1. `arr.length >= 3`
2. There exists some index `i` with `0 < i < arr.length - 1` such that:
   - `arr[0] < arr[1] < ... < arr[i]` (strictly increasing up to the peak), and
   - `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]` (strictly decreasing after the peak).

In other words:

- There must be a **strictly increasing** part, then
- A **strict peak** (not at the ends),
- Then a **strictly decreasing** part,
- No flats (`==`) allowed anywhere.

---

## Explanation (Two-Pointer, Single Scan Peak Pattern)

We use a **single index `i` that walks from left to right**:

1. **Strictly climb up:**
   - Start with `i = 0`.
   - While `i + 1 < n` and `arr[i] < arr[i + 1]`, move `i` forward.
   - After this loop, `i` is at the **candidate peak index**.

2. **Check peak validity:**
   - Peak **cannot** be at the start (`i == 0`) → no increasing part.
   - Peak **cannot** be at the end (`i == n - 1`) → no decreasing part.
   - If either happens, return `false`.

3. **Strictly climb down:**
   - Continue from this `i`:
   - While `i + 1 < n` and `arr[i] > arr[i + 1]`, move `i` forward.
   - At the end, if we reach `i == n - 1`, the array strictly decreased all the way to the end.

4. **Final condition:**
   - Return `true` only if `i == n - 1`.

Time complexity: `O(n)`  
Space complexity: `O(1)`

---

## Example Input

Example 1:

```
arr = [2, 1]
```

## Example Output

Example 1:

```
false
```

Explanation: Length < 3, and there is no valid mountain.

---

Another example:

### Input

```
arr = [0, 3, 2, 1]
```

### Output

```
true
```

Explanation:

- Increasing: `0 < 3`
- Peak at value `3` (index 1, not at ends)
- Decreasing: `3 > 2 > 1`
- All conditions are satisfied.

## Zig Solution (Zig 0.15.2)

```zig
const std = @import("std");

pub fn validMountainArray(arr: []const i32) bool {
    const n = arr.len;
    if (n < 3) return false;

    var i: usize = 0;

    // Walk strictly up
    while (i + 1 < n and arr[i] < arr[i + 1]) : (i += 1) {}

    // Peak cannot be first or last
    if (i == 0 or i == n - 1) return false;

    // Walk strictly down
    while (i + 1 < n and arr[i] > arr[i + 1]) : (i += 1) {}

    // Must end exactly at the last index
    return i == n - 1;
}

pub fn main() !void {
    // Example tests
    const example1 = [_]i32{ 2, 1 };
    const example2 = [_]i32{ 0, 3, 2, 1 };
    const example3 = [_]i32{ 0, 2, 2, 1 }; // not valid (flat at the top)
    const example4 = [_]i32{ 0, 1, 2, 3 }; // not valid (never goes down)

    std.debug.print("Example1: {any} -> {any}\n", .{ example1, validMountainArray(&example1) });
    std.debug.print("Example2: {any} -> {any}\n", .{ example2, validMountainArray(&example2) });
    std.debug.print("Example3: {any} -> {any}\n", .{ example3, validMountainArray(&example3) });
    std.debug.print("Example4: {any} -> {any}\n", .{ example4, validMountainArray(&example4) });
}
```
